❓ Dean Suite - Help & User Guide

Welcome to the InternLog Attendance & Verification System Dean's Suite. Below is a summary of available tools and shortcuts:

🔍 Global Search Bar:

Type student names, ID numbers (e.g. 2026-0009), course codes (BSCS, BSIS, BLIS), or partner facilities to instantly filter table rows in real-time.

🔔 System Notifications:

The bell icon pulses when students submit new attendance logs or absence requests. Click it to open a live queue popover.

📸 Attendance Verification Logs:

Review live facial capture snapshots. Click Confirm (green) to approve & delete verification photos from disk, or Reject (red) to require student follow-up.

📄 Absence Request Queue:

View student medical/official absence applications, supporting attachments, and provide administrative approval or rejection remarks.
